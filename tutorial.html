Um tutorial de HTML e CSS para o eu do futuro

O que é HTML?

HTML (HyperText Markup Language) é uma linguagem de marcação usada para criar e estruturar sites da internet. Ele é importamte para organizar o conteúdo de uma página, como títulos, textos, imagens, links e outros elementos que aparecem na página. O HTML é considerado a base do desenvolvimento web e normalmente é usado junto com outras tecnologias, como CSS e JavaScript.

Estrutura básica de um arquivo HTML

Ilustração de como seria uma estrutura de HTML:

                
                    <!DOCTYPE html>
                    <html>
                        <head>
                           <title>Título do site</title>
                        </head>
                        <body>
                            <h1>Olá, mundo!</h1>
                            <p>Este é meu primeiro site!</p>
                        </body>
                    </html>

Mas calma! Vamos por partes.
O que significam estas palavras juntas de < e >? Elas são chamadas de Tags! As Tags servem para marcar para o navegador o que é cada parte do site.
E como elas funcionam? As Tags seguem uma organização e hierarquia parecida com bonecas russas (uma dentro da outra), é importante cada Tag ficar no lugar certo para manter o código limpo e funcional.

Para que serve cada uma das Tags usadas anteriormente:

  • Não é exatamente uma Tag: "<!DOCTYPE html>" mas serve para dizer para o navegador que a versão do HTML sendo usada é a mais recente.
  • <html>: É a Tag que define o início e o fim do documento. Tudo que existe no site deve estar dentro dela.
  • <head>: A parte que o usuário não vê, dentro dela é feito as configuações, links para estilos (CSS) e metadados.
  • <title>: Define o título da página que aparece na aba do navegador.
  • <body>: É tudo o que você vê dentro do site, textos, imagens, botões. Tudo que é para ser visível fica aqui dentro.
  • <h1>: Representa o título principal e o destaque do conteúdo.
  • <p>: Define um parágrafo. É a tag padrão para textos comuns e blocos de leitura.
Tags importantes de HTML

Existem inúmeras Tags com diferentes funções, aqui estão algumas das tags principais de HTML:

Organização de Texto

<h1> a <h6>: São títulos que possuem hierarquia de importância. O <h1> é o mais importante e o <h6> sendo o menos.

<p>: Define um parágrafo.

<br>: Quebra a linha, funcionando tipo "Enter" mas o texto continua junto da linha de cima, apenas embaixo.

<ul>: Cria uma lista com marcadores (bolinhas).

<ol>: Cria listas numeradas.

<li>: É usado para indicar um item da lista, funciona tanto em <ul> quanto em <ol>.

<strong>: Deixa o texto em negrito Obs: Também existe <b>, porém <b> só deixa em negrito visualmente, leitores de tela não entendem que está em negrito.

<em>: Deixa o texto em itálico. Obs: É igual o negrito e a Tag que só funciona visualmente é <i>

Elementos de mídias e links

Para tornar o site interativo e visual

<a>: Cria um link.
Como usar: Assim que você digita essa Tag ela abre com o atributo "href", dentro das aspas dele você coloca o seu link. E depois você escreve entre: <aqui>/a> uma descrição do seu link.
Difícil de visualizar? Exemplo:
Formato: <a href="o link vem aqui">descrição aqui</a>

Além disso, existem três tipos de links:

Links Externos - Levam para outro site. Exemplo:
<a href="https://google.com">Ir para o Google</a>

Links Internos para outra página - Levam para outra página do seu próprio site.
Imagine que você tem dois arquivos na sua pasta do VSCode: index.html (a principal) e sobre.html (sua biografia)
Para ir da página principal para a biografia, você pode escrever assim: <a href="sobre.html">Clique aqui para ler minha biografia</a>
Obs: O nome dentro do href tem que ser exatamente igual o nome do arquivo.

Links Internos para a mesma página - Levam para algum lugar em específico da página.
Quando um site é bem comprido é comum de ter um botão de "Voltar ao topo" ou um menu que consegue te levar para um lugar específico. Isso é chamado de link interno usando IDs.
Como usar: Vá no lugar onde quer chegar e dê um nome (ID), Exemplo: <h2 id="olhos-verde"<Porque olhos verdes são tão bonitos:</h2>
E depois você cria o link usando "#" antes do nome que você criou, exemplo:
<a href="#olhos-verdes">Descobrir o motivo de olhos verdes serem tão bonitos</a>

Extra: Caso queira que o link abra em uma nova aba, adicione: target="_blank"
Exemplo: <a href="site.com" target="_blank">Abrir em nova aba</a>

<img>: Insere uma imagem.
Como usar: Ela precisa de dois atributos essenciais.
Um deles é "src" que é o caminho do arquivo da imagem, pode ser um link ou uma pasta no seu computador.
E o outro que é "alt", uma descrição da imagem. É importante para acessibilidade (leitores de tela para cegos) e para o Google entender o que é a foto.
Exemplo: <img src="foca-fofa.jpg" alt="Foto de uma foca">

<button>: Cria um botão clicável.
Como usar: O que você escrever entre <button> e <button> vai aparecer dentro dele.
A Tag <button> precisa de um atributo chamado type para dizer ao navegador a função do botão, existem vários tipos de type mas um bem importante:

Botão Customizável (type="button"): É o botão "vazio". Ele sozinho não faz nada. As pessoas usam ele quando vão adicionar uma função persoonalizada depois. Exemplo: <button type="button">Eu sou inútil</button>

Estruturação (Layout)

<div>: Uma divisão genérica.

<header>: O topo do site ou de uma seção.

<main>: O conteúdo principal da página.

<footer>: Final da página.

<section>: Define uma seção temática no documento.

O que é CSS?

CSS (Cascading Style Sheets) é a linguagem usada para definir a aparência de uma página feita em HTML. Ele controla coisas como: cores, fontes, tamanhos, posicionamentos, adaptação para o celular e até animações. A estrutura básica de CSS é dividida em três partes principais:

Seletor: Indica qual elemento da sua página você quer estilizar, ex: h1, p, button, etc.

Propriedade: O que você quer mudar, ex: color, font-size, etc.

Valor: A nova configuração, ex: green, 20px, etc.

No final deve ficar algo assim:

            
                h1 {
                    color: blue
                }

Como aplicar o CSS: Existem três maneiras, mas a mais recomendada é o CSS Externo, onde você cria um arquivo .css separado e vincula ao seu HTML desta maneira:

            
                <head>
                    <link rel="stylesheet" href="estilo.css">
                </head>

Obs:Botões também são estilizáveis com CSS!

Classes e IDs

Classe é uma etiqueta de categoria, se você quer que vários elementos tenham a mesma aparência, você usa a mesma etiqueta neles.
Ela é importante por conseguir aplicar e mudar alguma estilização de maneira prática, sem ter que ser um por um. Também é muito útil por não afetar as Tags em si.
Você também pode usar a mesma classe em quantos elementos quiser e um elemnto pode ter várias classes ao mesmo tempo!

Exemplo:

            
                No HTML:
                <p class="destaque">Eu sou um parágrafo importante!</p>
                <p>Eu sou um parágrafo comum.<p>
                <h1 class="destaque">Eu sou um título importante!</h1>
                No CSS:
                .destaque {
                    color: green;
                    font-weight: bold;
                }

Caso você usasse ficaria literalmente assim:

Eu sou um parágrafo importante!

Eu sou um parágrafo comum.

Eu sou um título importante!

Diferente da Classe, o ID serve para identificar um elemento único da página, você só pode ter um elemento com um ID específico.
Ele é usado quando você quer dar estilo a algo que não se repete. Por exemplo: A barra de navegação, o rodapé ou um contato específico.

Exemplo de código:

            
                No HTML:
                <p id="descricao">Eu sou um texto que descreve algo, talvez a cor bonita que eu tenho.</p>
                No CSS:
                #descricao {
                    color: green;
                    font-style: italic;
                }

Como ficaria na prática:

Eu sou um texto que descreve algo, talvez a cor bonita que eu tenho.

Obs: O CSS entende que você está pedindo para ele procurar por classes se você usar "." no começo, e por IDs se você usar "#".
